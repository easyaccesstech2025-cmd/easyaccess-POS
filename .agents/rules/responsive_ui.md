# Responsive Design & UI Rule

1. **Mobile-First Responsiveness:** All pages, components, and UI layouts created or modified in this project MUST be fully responsive and optimized for mobile devices (phones), as well as tablets and desktop screens. 
2. **Tailwind Breakpoints:** Always use Tailwind's responsive prefixes (`sm:`, `md:`, `lg:`) to ensure layouts adapt gracefully to different screen sizes. Avoid fixed widths that break on mobile.
3. **Collapsible Navigation:** The main left panel menu bar (Sidebar) must be collapsible to save screen space on mobile devices and provide a toggle button to open/close it.
